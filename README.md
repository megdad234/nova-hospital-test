# NOVA Hospital — Windows installer test

This public repository is for **development-only Windows installer testing**. Do not use its builds with real patient records until Windows, LAN, backup/restore and security acceptance are completed.

To run the build, the full authorized source archive must be placed at the repository root as `NOVA_Hospital_GitHub_Ready_Source.zip`.

**Important:** This repository is public. Do not upload real patient data, database backups, passwords, or other secrets.
