# NOVA: تحديث الأسعار الجماعي

حالة العمل: فرع منفصل للتنفيذ والفحص، لم يُدمج في main.

- لا يشترط المورد عند رفع البرايس.
- آخر سعر شراء مرجعي هو آخر شراء فعلي للصنف من جميع الموردين، وليس آخر برايس.
- لا تُغيّر أسعار الشراء التاريخية أو تكاليف المخزون أو الكميات أو الفواتير.
- الحساب الافتراضي يحافظ على نسبة الزيادة الحالية فوق آخر تكلفة شراء فعلية لكل عبوة.
- نسبة جماعية اختيارية، ثم تعديل سعر البيع يدوياً لكل صنف.
- تُحدد الأصناف المتغيرة فقط افتراضياً.
- مطابقة دقيقة بالباركود والاسم والتركيز والعبوة؛ المطابقات غير المؤكدة للمراجعة.
- معاينة ثم اعتماد ذري بصلاحيات وتدقيق، وتراجع آمن مع كشف التعارضات.
- إعادة استخدام منطق المشتريات والتسعير الموجود وعدم تكراره.

قبل الربط بالإنتاج: استخراج المصدر الأساسي من ZIP، دمج Batch 01–14، فحص استيراد Excel والمشتريات، اختبارات SQLite/Windows وواجهة المستخدم. لا اعتماد قبل نجاح الاختبارات.
